Myoelectric Prosthetic Hand

Designed an affordable, customizable upper-limb prosthetic for amputee rehabilitation. The design uses surface EMG electrodes to measure muscle activity, mapped via microcontrollers to actuator motion.

Key Highlights:

  • Custom 3D-printed chassis using PETG filament.
  • Real-time notch and bandpass filtering on raw EMG data.
  • Multi-grip pattern state engine.

ECG Filtering Pipeline

Engineered a robust MATLAB pipeline designed to eliminate 60Hz powerline interference and baseline wander from continuous electrocardiogram datasets.

Key Highlights:

  • Implemented Pan-Tompkins algorithm for R-peak detection.
  • Achieved 98.2% signal retention across 50 test sets.
